# The Code Warrior

Free coding lessons for beginners on YouTube: [@askthecodewarrior](https://www.youtube.com/@askthecodewarrior).

## Python: Zero to Warrior
A free Python course that starts from zero. You type every line yourself in VS Code, and each lesson ends with a
"your turn" exercise.

- Code and practice problems: [python-zero-to-warrior](https://github.com/askthecodewarrior/python-zero-to-warrior)
- Full course playlist: https://www.youtube.com/playlist?list=PLcsbg964FAwc

New lessons show up in the repo as their videos come out.
